PWA Library は、zip にまとめられた Web アプリ（index.html とその一式）を取り込み、ホーム画面から普通のアプリのように起動できるようにします。開発者ではなく、zip を受け取って使いたいだけの人のためのアプリです。

<b>できること</b>

• ファイル選択、共有シート、ファイルマネージャから zip を取り込む
• Web マニフェストの名前とアイコンで一覧に並べる。マニフェストが無ければ HTML から読み取る
• ホーム画面にピン留めする。アプリごとに別のウィンドウで開く
• 新しい zip を取り込むとその場で更新する。アプリが保存したデータは残る
• 名前の変更、アイコンの差し替え、zip の書き出しと共有

<b>パーミッションなし、通信なし</b>

このアプリは Android のパーミッションを一つも宣言していません。インターネット接続もありません。素性の分からない zip を動かしても、外に出る経路が無いので何も送信できません。取り込んだアプリはそれぞれ別の origin から配信され、localStorage、IndexedDB、キャッシュはアプリごとに分かれます。

そのため、スクリプトやデータをインターネットから読み込むアプリは動きません。必要なものがすべて zip に入っているアプリは動きます。

<b>ストレージ権限なしでファイルを扱う</b>

取り込んだアプリは標準の File System Access API（showDirectoryPicker など）を使えます。システムの選択画面でフォルダを選ぶと、そのアプリはそのフォルダだけを読み書きでき、再起動後も続けて使えます。許可はアプリの詳細画面から取り消せます。ページが始めたダウンロードは、選んだ場所に保存されます。

<b>中で動くもの</b>

Service Worker、IndexedDB、Cache Storage、Web Worker、WebAssembly、WebGL、フルスクリーン、ファイル入力。Vite でビルドした SPA や Next.js の静的出力はそのまま動き、サブパス配下を前提にしたビルドにも対応しています。

<b>既知の制限</b>

• 取り込んだアプリは通信できません（設計どおり）
• Web 通知は Android の WebView が対応していません
• カメラ、マイク、位置情報の要求は拒否されます
• SVG しか無いアイコンは描画されず、頭文字のタイルになります。画像を自分で選べます
• システムのフォルダ選択では Download フォルダとストレージのルートを選べません
